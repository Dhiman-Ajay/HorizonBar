# HorizonBar
HorizonBar: Persistent Horizontal Tab Manager

HorizonTab is an experimental browser extension built for users who prefer horizontal tab workflows and want faster, cleaner tab navigation across Chromium-based browsers.

Recent Chromium UI changes reduced support for persistent horizontal tab scrolling, while many users still find vertical tabs uncomfortable or inefficient for multitasking. HorizonTab restores a lightweight horizontal tab experience with a modern floating dock interface.

✨ Features
📌 Persistent floating horizontal tab bar
⚡ Fast tab switching
🧩 Compact mode for minimal screen usage
🔇 Quick mute/unmute controls
🪟 Active window tab management
🧠 Lightweight workflow-focused UI
📚 Designed for multitasking and large tab counts


## 🧪 Experimental Status

HorizonTab is currently in early development.

Some features and behaviors may still be unstable depending on browser updates and system configurations. Certain shortcuts and window-switching interactions may not always behave consistently across all Chromium browsers.

You may encounter:

🐞 Bugs
🎨 UI inconsistencies
⚠️ Unexpected edge cases
🔄 Browser-specific behavior differences
💡 Feedback & Feature Requests

Bug reports, feedback, and feature suggestions are highly appreciated and help improve the extension faster.

👉 Please report issues or request features through the GitHub page.

## 🔒 Privacy

HorizonTab does not collect, store, or sell personal browsing data.

Required browser permissions are only used for:

📑 Detecting open tabs
🔀 Switching tabs
🔇 Managing mute state
📌 Maintaining the floating tab interface
